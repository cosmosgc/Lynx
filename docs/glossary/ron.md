# RON

**RON** means Rusty Object Notation. It is a text format for structured data,
similar in purpose to JSON, that is comfortable to read and write alongside
Rust projects. For example, a RON file can describe an item or zone using
named fields and lists.

In Lynx, RON is the canonical format for authored game content. Content is
validated before it is loaded or published; RON files are data, not executable
game logic. See [content authoring](../content-authoring.md#formats).
