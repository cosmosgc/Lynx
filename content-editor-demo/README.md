# content-editor-demo

This project was generated by the Lynx project CLI.

Authored game data lives in `content/`. The world map, two connected starter zones, interactable tavern keeper, a typed lever-to-gate link, torch item, inventory panel, and Brazilian Portuguese source catalog are ready for `lynx validate --project .`. Use `lynx build --project .`, `lynx run --project .`, or `lynx test --project .` to validate and invoke Cargo. This starter executable is not yet a playable game server.

Interactions describe client intent only; the authoritative game server must validate each request and determine its outcome.
