# Embedded UI font

Unmodified `FiraMono-Regular.ttf`, downloaded from
https://github.com/google/fonts/tree/main/ofl/firamono on 2026-11-05.
Redistributed under `OFL.txt`. Replaces Bevy's ASCII-oriented subset at the
default font asset ID, including Portuguese accents in UI and nameplates.
The font is embedded in the executable; no runtime file lookup is required.
